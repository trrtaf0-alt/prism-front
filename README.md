# Prism Front v0.8.0

Windows와 Android에서 플레이하는 2D 타워 디펜스입니다. 일반 재화로 타워를 배치하고 적을 처치해 연구 포인트(RP)를 모으세요. 총 109개 연구에서 타워 43종을 해금할 수 있습니다. 기본 포탑을 포함한 공격·특수 타워 29종, 지원 타워 6종, 경제 타워 9종이 있습니다. 캠페인은 50웨이브로 구성되며 보스는 마지막 웨이브에 한 번 등장합니다. [몹 능력치와 출현 비율](MOBS.md) · [캠페인 밸런스](BALANCE.md) · [지원 타워](SUPPORT.md)

## 실행과 조작

Windows 10/11 64비트용 설치판과 무설치판은 [GitHub 릴리즈](https://github.com/trrtaf0-alt/prism-front/releases/latest)에서 받을 수 있습니다. `PrismFront-Setup-Windows-x64.exe`로 설치하거나 `PrismFront.exe`를 바로 실행합니다. 설치판은 현재 사용자 계정에 설치하고 기본으로 바탕화면 바로가기를 만듭니다. ZIP 배포판은 모두 압축을 푼 뒤 실행 파일을 더블 클릭합니다. 게임 리소스와 한글 글꼴은 EXE에 내장됩니다.

Android 7.0 이상에서는 같은 릴리즈의 `PrismFront-v0.8.0-Android.apk`를 내려받아 설치합니다. 가로 화면에서 터치로 플레이할 수 있습니다.

소스를 실행하려면 Godot 4.7.2에서 `project.godot`을 가져온 뒤 F5로 실행하세요. Windows Desktop 릴리스 내보내기 뒤 [Inno Setup 6](https://jrsoftware.org/inno-setup/downloads)의 `ISCC.exe`로 `packaging/Windows.iss`를 컴파일하면 설치용 EXE를 다시 만들 수 있습니다.

- 전장은 화면 전체에 표시됩니다. 웨이브와 자원은 위쪽, 타워 배치와 연구는 아래쪽 HUD에 표시됩니다. 배치한 타워를 선택하면 세부 정보와 판매 버튼이 나타납니다.
- **타워 선택**에서 해금된 타워를 고르면 곧바로 배치가 시작됩니다. **전체**에서 잠긴 타워의 연구도 확인할 수 있습니다. **1** 또는 HUD의 포탑 버튼으로 같은 타워를 빠르게 배치합니다. 타일 옆에서 조준 범위와 설치 가능 여부를 확인하고, 좌클릭으로 계속 배치하거나 **Esc**·우클릭으로 취소합니다.
- **타워 선택**에서 카드에 마우스를 올리거나 키보드로 포커스를 옮기면 설치비, 기본 피해, 주기, 사거리, 특수 효과가 표시됩니다. 배치 모드에서는 선택한 타워의 기본 능력치를 화면 왼쪽에서 확인할 수 있습니다.
- 전장에서 마우스 휠로 확대·축소하고 휠을 누른 채 드래그해 이동합니다. 상단 배율 버튼을 누르면 기본 보기로 돌아갑니다. 적 위에 마우스를 올리면 본체 HP와 보호막의 현재값과 최대값을 볼 수 있습니다.
- 메인 메뉴와 전투 HUD의 **도감**, 또는 **K**로 타워 44종과 적 21종(분열체·증식체 포함)의 상세 수치를 확인합니다. 적 탭에서 웨이브와 난이도를 바꿔 실전 수치를 비교할 수 있습니다.
- 배치된 타워를 클릭해 사거리와 능력치를 확인하고 판매합니다. 기본 포탑은 100%, 추가 타워는 초안으로 75%를 정수 단위로 환급합니다.
- **게임 시작**에서 쉬움·보통·어려움을 선택합니다. **다시 시작**은 같은 난이도로 새 판을 열며 클리어 기록은 난이도별로 저장됩니다. [난이도별 수치](BALANCE.md#난이도)
- 난이도 선택창의 **커스텀 규칙**에서 11개 항목을 조절합니다. 음수는 제약, 0은 기본, 양수는 특전입니다. 타워 설치 수는 −5~0단계입니다. 시작자금은 추천 금액을 누르거나 직접 입력할 수 있고, 시작 RP도 따로 입력할 수 있습니다. 모두 초기화하면 시작자금 50, 시작 RP 0, 모든 항목 0단계로 돌아갑니다. 적용 효과와 시작 자원은 해당 판에만 적용되며, 커스텀 규칙을 적용한 판은 일반 난이도 기록과 별개입니다. 재화와 RP 보상의 소수점은 해당 판 안에서 각각 누적합니다.
- 웨이브 시작 전에 주요 적 유형과 수를 확인할 수 있습니다. **웨이브 시작**으로 교전을 시작합니다. 49웨이브까지는 완료 뒤 다음 웨이브를 수동으로 엽니다. 50웨이브에서는 보스와 지원군이 연달아 등장합니다. 보스를 처치하고 남은 적을 정리해 기지를 지키면 승리합니다.
- **연구** 또는 **R**로 연구 화면을 열고 드래그와 휠로 이동·확대합니다. **전체 보기**, 구역 버튼, **타워 연구 찾기**로 이동할 수 있습니다. 노드를 선택하면 선행 조건, 최소 남은 RP, 연결된 경로와 결과가 표시됩니다. **연구 완료**를 누르면 해당 연구만 구매합니다.
- 기본 적은 설치 재화 3을 지급합니다. 처치 RP는 적 유형과 웨이브에 따라 달라집니다. 연구를 초기화하려면 새 게임을 시작합니다. 최고 웨이브와 볼륨·화면·전투 효과 설정은 유지됩니다.
- 배치한 타워의 **지원 상태**에서 실제 배율, 적용 범위, 제공 시설과 특수 능력 타이머를 확인할 수 있습니다.
- 연구망의 새 구역에서 첫 연구를 완료하면 해금음이 울리고, 연구 화면의 강조색이 도달한 최고 구역에 맞춰 바뀝니다.
- 메인 메뉴와 일반 전투에서는 **잔광의 방어선**이 재생됩니다. 50웨이브에 보스가 등장하면 **코어의 그림자**로 전환되고, 보스를 격파하면 일반 전투곡으로 돌아갑니다. **설정 → 배경음악 볼륨**에서 음악을 따로 조절할 수 있습니다.
- **Esc**는 화면을 닫거나 일시정지합니다. **설정 → 전투 효과 설정**에서 렌더링 품질, 파티클 밀도, 섬광, 화면 흔들림, 순간 줌, 충격 왜곡, 강한 밝기 감소를 조절합니다. 화면 움직임과 왜곡은 각 슬라이더를 0%로 내려 끌 수 있습니다.

연구 화면은 기본적으로 웨이브 중에도 열 수 있으며 열린 동안 전투를 멈춥니다. `data/balance.json`의 `research_available_during_wave`와 `research_pauses_battle`로 바꿀 수 있습니다.

## 타워

| 구역 | 타워 |
| --- | --- |
| 기본 | 기본 포탑 |
| 1단계 | 속사포, 관통포, 산탄포, 냉각포 |
| 2단계 | 전기포, 유탄포, 화염방사기, 저격포, 표식 타워, 레이저포, 미사일포 |
| 3단계 | 레일건, 플라즈마 타워, 빙결 타워, 분열포, 회귀포, 궤도포, 프리즘 타워, 중력포 |
| 4단계 | 소용돌이 타워, 펄스 캐논, 폭풍 타워, 초신성 타워, 광자포, 파멸포 |
| 5단계 | 특이점 타워, 스펙트럼 타워, 카타클리즘 |
| 지원 | 전술 중계기, 조준 증폭기, 에너지 공명기, 과부하 증폭기, 양자 연결망, 전장 지휘 코어 |
| 경제 | 자원 수집기, 물질 합성기, 물질 생성로, 연구 분석기, 연산 허브, 양자 연산기, 생산 증폭기, 연구 증폭기, 산업 통합 코어 |

- 경제 타워는 웨이브 시작부터 완료까지 유지하면 재화나 RP를 한 번 생산합니다. 증폭기도 해당 웨이브 내내 유지해야 합니다. 같은 종류의 보너스는 한 번만 적용하며 전용 증폭기와 산업 통합 코어는 각각 최대 +20%, +30%를 더합니다. 커스텀 규칙의 재화·RP 배율은 증폭 이후 적용됩니다.

- **특이점**은 전장 전체에서 10초마다 발동해 4초 동안 0.2초마다 피해 850과 이동 속도 40% 감소를 적용합니다. 종료 시 붕괴 충격파가 퍼집니다.
- **프리즘**은 최대 4기, **광자포**는 전장 전체에서 최대 12기를 동시에 조준합니다.
- **스펙트럼**은 0.1초마다 전장 전체의 적 각각에게 피해 420을 가합니다. 굴절 광선은 대상 일부를 시각적으로 표시합니다.
- **카타클리즘**은 상공 구조물과 충전 고리를 전개해 3.5초 충전 뒤 전장 전체에 100,000 피해를 가합니다. 주기는 8초입니다.

전기 공격은 첫 경직 0.2초에서 시작합니다. 연속 적중 시 경직은 짧아지고 경직 사이 이동 시간이 보장됩니다. 적중이 멈추면 저항이 회복됩니다. 표식은 다른 타워의 최종 피해에 적용되며 소수점 피해는 올림합니다. 중력포는 반경 7칸에 피해 18와 이동 속도 30% 감소를 적용합니다. 중력 둔화와 빙결이 겹치면 남은 이동 속도 배율을 곱하며, 중력 둔화끼리는 가장 강한 효과가 적용됩니다.

| `scripts/profile.gd`, `scripts/sound.gd` | 설정·최고 기록 저장과 합성 효과음 |

새 타워는 기존 공격 구성요소와 파라미터를 재사용하고, 새 연구 노드에서 해당 ID를 참조합니다. 조건은 ID 문자열, `all`, `any`의 재귀 조합으로 작성합니다. 조건식이 올바르지 않거나 해금 관계에 오류가 있으면 시작 화면에서 표시합니다. 새 적과 편성은 `data/enemies.json`에 정의합니다. `EnemyRegistry`는 생성 관계를 검증하고 `WaveRoster`는 각 웨이브의 슬롯을 순서대로 추첨합니다.

최종 사용자 맵은 같은 스키마로 `data/map.json`을 추가하면 적용됩니다. 좌표는 0부터 시작하는 `[x, y]`입니다. `.`는 빈칸, `#`는 장애물, `=`는 경로, `S`는 시작, `E`는 출구입니다. 30자씩 18행을 작성하고 연결된 `path`를 선언합니다.

## Android에서 플레이

가로 화면에서 사용할 수 있습니다. 타워를 선택하고 설치할 칸을 한 번 눌러 미리 본 뒤, 같은 칸을 다시 눌러 설치합니다. 설치 모드 밖에서 타워를 누르면 능력치와 판매 버튼이 표시됩니다. 전장은 두 손가락으로 확대·축소하고 확대 상태에서 한 손가락으로 이동합니다. 연구망은 한 손가락 드래그로 이동하고 두 손가락으로 확대·축소합니다. 노드를 누른 뒤 **연구 완료**를 누르면 확정됩니다.

모바일은 기본 전투 효과 품질을 낮음으로 시작합니다. **설정 → 전투 효과 설정**에서 품질과 파티클 밀도 등을 조절할 수 있습니다.

Android APK를 만들려면 Godot 4.7.2의 Android 내보내기 템플릿을 설치하고, 에디터 설정에서 JDK와 Android SDK 경로를 지정합니다. 다음 명령은 설치 테스트용 디버그 서명 APK를 생성합니다. [Godot Android 내보내기 안내](https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_android.html)

```powershell
& $Godot --headless --editor --path . --import --quit
New-Item -ItemType Directory -Force dist | Out-Null
& $Godot --headless --path . --export-debug Android dist/PrismFront.apk
```

## 모드 관리

메인 메뉴의 **모드 관리 → 모드 추가**에서 ZIP을 선택한 뒤, 목록에서 모드를 활성화하고 새 게임을 시작합니다. Windows에서는 모드 관리 화면에 ZIP을 끌어다 놓을 수도 있습니다. Android에서는 기기의 파일 선택기를 엽니다. 비활성화하면 설치본은 남습니다. 삭제는 확인 후 선택한 모드에만 적용되며, 모드 적용 판은 일반 기록과 별개입니다.

모드 ZIP의 루트에 `mod.json`과 콘텐츠 JSON을 넣습니다. 압축 파일은 최대 1 MiB이고 각 JSON은 최대 256 KiB입니다. 모드는 데이터만 추가하며 기존 ID, 전투 규칙, 웨이브 수와 최종 보스는 유지합니다.

```json
{
  "format": 1,
  "id": "example",
  "name": "예시 모드",
  "author": "작성자",
  "version": "1.0",
  "description": "추가 콘텐츠 설명",
  "requires": []
}
```

| 선택 파일 | 루트 구조 | 기존 데이터 예시 |
| --- | --- | --- |
| `towers.json` | `{"towers": [...]}` | `data/towers.json` |
| `research.json` | `{"nodes": [...]}` | `data/research.json` |
| `enemies.json` | `{"enemies": [...]}` | `data/enemies.json` |

ID는 소문자와 숫자로 시작하며 점, 밑줄, 하이픈을 덧붙일 수 있습니다. 추가 타워와 해금 연구는 `research_id`와 `unlock.id`로 연결합니다. 다른 모드의 데이터가 필요하면 `requires`에 해당 모드의 ID를 적습니다. 의존 모드를 먼저 적용하고 나머지는 모드 ID 순으로 검사합니다. 충돌하거나 의존성이 충족되지 않은 모드는 보류 사유가 표시됩니다. 새 타워는 기본 아트를 사용하며, ZIP에서 스크립트나 별도 리소스를 불러오지 않습니다.

## Windows 내보내기

[Godot 4.7.2 안정 버전](https://godotengine.org/download/archive/4.7.2-stable/)과 같은 버전의 표준 내보내기 템플릿을 준비합니다. 프로젝트 루트에서 PowerShell로 실행합니다.

```powershell
$Godot = 'C:/path/to/Godot_v4.7.2-stable_win64_console.exe'
& $Godot --headless --editor --path . --import --quit
New-Item -ItemType Directory -Force dist | Out-Null
& $Godot --headless --path . --export-release 'Windows Desktop' dist/PrismFront.exe
```

배포에는 `assets/Godot-LICENSE.txt`, `assets/Godot-COPYRIGHT.txt`, `assets/OFL.txt`의 고지가 포함됩니다. 테스트 방법과 실제 측정값은 [TESTING.md](TESTING.md)에서 확인할 수 있습니다.
